# netdrive

朝PCを開いたら、いつもの共有が決まったドライブ文字でつながっているための、タスクトレイ常駐の単一exeです。

## 使い方

```powershell
dotnet publish -c Release -o out
out\netdrive.exe
```

- 一覧の1行が1ドライブです。ドライブ文字・接続先（ホスト／共有名）・ユーザー・自動接続のON/OFFを持ちます。
- 種別は「ネットワーク共有」と「ローカルフォルダ」から選べます。ローカルフォルダは、`subst` と同じ仕組みでドライブ文字に割り当てます。割り当ては再起動で消えるため、起動のたびに自動で付け直します。
- 「接続」「切断」ボタンで、選んだ行を手動で操作できます。自動接続がOFFの行は、「接続」を押したときだけつながります。
- 追加・編集の画面にある「既存の接続から選ぶ…」で、現在の接続・永続設定・入力履歴から候補を選べます。選ぶと、ホスト・共有名・ユーザー（とドライブ文字）が入ります。パスワードは読み取れないため、ログインが必要な接続先は自分で入力してください。
- ウィンドウを閉じてもトレイに常駐します。終了はトレイアイコンの右クリックメニューから行います。
- 設定は `%APPDATA%\netdrive\netdrive.json` に保存されます。旧形式の設定は起動時に自動で移行します。

## 繋がらないとき

- **届かない間**（VPN確立前・社外など）: 静かに待って再試行します。間隔は10秒から始めて、最大5分まで延ばします。スリープ復帰とネットワーク変更の直後は、待たずに確認します。
- **認証エラー・共有名の誤り・権限不足・別の資格情報での接続済み**: 再試行を止め、状態欄に理由を出し、トレイから通知します。直したあとに「接続」を押すと再開します。アカウントのロックを避けるためです。
- **別の共有が同じ文字に割り当て済み**: 既存の接続を壊さないよう、触らずに止めます。

## パスワード

設定ファイルには保存しません。入力すると、Windows 資格情報マネージャーに保存されます（OSが暗号化して保持します）。空欄なら既存の登録を使います。

## 前提

- 実行する側にインストールは要りません（.NET 8 のランタイムを exe に同梱しています。約68MB）。
- ビルドには .NET 8 SDK 以上が必要です。Visual Studio 2022 で開いて編集できます。
